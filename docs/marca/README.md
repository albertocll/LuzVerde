# marca

Imágenes de Luz Verde para tiendas y redes. El icono es el mismo semáforo de `mobile/assets/icon.png`.

| archivo | tamaño | uso |
|---|---|---|
| `icono-512.png` | 512 x 512 | Icono de alta resolución en Google Play Console |
| `feature-graphic.png` | 1024 x 500 | Gráfico de funciones en Google Play Console |
| `social-preview.png` | 1280 x 640 | Social preview del repo en GitHub y `og:image` de la web |

Colores: fondo `#0F3D2E`, verde del semáforo `#22C55E`, texto `#E9F5EE`.
Fuentes: Bricolage Grotesque (título) e Instrument Sans (texto), las mismas que la web.

La social preview no se lee del repo. Se sube a mano en Settings > General > Social preview > Edit > Upload an image.
